# Discord Bot Hub

Discord Bot Hub is a premium source code repository containing multiple beginner-friendly Discord bots. Each bot is packaged in its own directory with a dedicated installer, configuration system, documentation, and VPS deployment process.

## Included Bots

- Moderation Bot
- Economy Bot
- Ticket Bot
- Giveaway Bot
- Leveling Bot
- Music Bot
- AI Chat Bot
- Verification Bot
- Utility Bot
- Marketplace Bot

## Quick Start

1. Upload the repository to your VPS.
2. Run `bash install.sh` from the repo root.
3. Follow the interactive installer and choose your bot.
4. The selected bot will install dependencies and configure PM2 automatically.

## Requirements

- Ubuntu 20.04+ / Debian-based Linux
- Node.js 20.x
- npm
- PM2
- Git
