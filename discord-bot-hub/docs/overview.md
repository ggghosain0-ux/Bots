# Discord Bot Hub Documentation

This repository is built for sellers who want a professional Discord bot package for VPS deployment.

## Goals

- Beginner-friendly installation
- Modular bot architecture
- PM2 support for reliable uptime
- Built-in configuration system
- Example database integration
- Detailed documentation per bot

## Installation Flow

1. Run `bash install.sh` from the repository root.
2. Choose the bot you want to install.
3. Provide the bot token, IDs, and configuration values.
4. The installer creates `.env`, installs dependencies, and starts PM2.

## Support

For each bot, open its `README.md` to review specific commands, configuration options, and troubleshooting notes.
